Rail is a next-generation payments infrastructure platform that gives developers a single, unified REST API to build compliant financial products spanning both fiat currencies and digital assets. Whether you're embedding a wallet, powering a crypto on-ramp, or orchestrating multi-rail money movement, Rail handles the complexity — KYC/KYB verification, AML screening, fraud checks, regulatory compliance — so your team can focus on building great products.

## How Rail works

Every integration follows the same high-level flow, regardless of the product you're building:

1. **Onboard** — Create an Application for your individual or business customer and submit it for compliance review. Rail performs KYC/KYB and AML checks automatically.
2. **Open an account** — Once an application is approved, open one or more Accounts for the customer. Accounts hold balances in fiat (USD) or supported digital assets (ETH, BTC, stablecoins).
3. **Transact** — Move money via Deposits, Withdrawals, Transfers, Exchanges, or Payments. Rail routes each transaction across the appropriate rails and keeps your webhooks informed in real time.

<Note>
  All API interactions require an OAuth2 access token obtained using your client credentials. See the [Authentication guide](/get-started/authentication) to get set up in under five minutes.
</Note>

## Key capabilities

Rail exposes a consistent set of resources through its REST API. Every resource follows the same request and response conventions, uses the same authentication model, and emits the same webhook event structure.

| Resource | What it does |
|---|---|
| **Applications** | Capture and submit customer onboarding data for compliance review |
| **Customers** | Represent approved individuals or businesses on your platform |
| **Accounts** | Hold balances in fiat or digital assets |
| **Counterparties** | External bank accounts or wallets for sending/receiving funds |
| **Deposits** | Receive funds into a Rail account |
| **Withdrawals** | Send funds from a Rail account to a counterparty |
| **Transfers** | Move funds between two Rail accounts |
| **Exchanges** | Convert between fiat and digital assets |
| **Payments** | Initiate outbound payments or collections |
| **Webhooks** | Subscribe to real-time event notifications |

## API base URLs

Rail provides separate environments for development and production. Always build and test against the sandbox before pointing your integration at production.

| Environment | Base URL |
|---|---|
| **Sandbox** | `https://sandbox.layer2financial.com/api` |
| **Production** | `https://platform.layer2financial.com/api` |
