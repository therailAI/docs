## Install

```bash
pip install therail-sdk
```

Requires Python 3.12 or later. The import name is `rail_sdk`. The client is synchronous and uses `httpx`.

## Read your context

Against the [local sandbox](/get-started/sandbox), take the CA path and a token from the CLI:

```bash
export RAIL_SANDBOX_CA="$(rail sandbox ca)"
export RAIL_TOKEN="$(rail sandbox token)"
```

```python
import os
import ssl

import httpx
from rail_sdk import RailClient

tls = ssl.create_default_context(cafile=os.environ["RAIL_SANDBOX_CA"])
rail = RailClient("https://localhost:8443", lambda: os.environ["RAIL_TOKEN"],
                  client=httpx.Client(verify=tls, timeout=30, follow_redirects=False))

context, _ = rail.call("getContext")
print("signed in as", context["principal_id"], context["project_ids"])

for grant in rail.paginate("listAuthorityGrants"):
    print(grant["id"], grant["state"])
```

The second argument is a token supplier, called before each request. For a long-running process, return a fresh token from your identity provider; don't embed a token in source code.

A client uses one base URL. The sandbox gateway routes every customer path, so one client covers all products there. In an operator environment without a gateway, create one client per service address.

## Product methods

Methods are grouped by product: `execution`, `authority`, `evidence`, `assets`, `lineage` and `settlement`, in snake_case. The generic `call` takes the contract's camelCase operation ID and also accepts `headers`.

```python
data, headers = rail.execution.get_execution(path={"execution_id": execution_id})
print(data["state"], data["external_effect"], headers.get("etag"))
```

Calls return the decoded body and the response headers. Keyword arguments: `path`, `query`, `idempotency_key` (required on every mutation), `if_match`, and on `call` also `headers` and `deadline` (a `time.time()` value that automatic retries never wait past).

## Idempotency keys

```python
from rail_sdk import new_idempotency_key

rail.execution.create_action(body, idempotency_key=new_idempotency_key())
```

Make a fresh key per decision and reuse it only to retry that same request. See [idempotency](/api-reference/idempotency).

## Long-running operations

```python
operation = rail.wait_for_operation(operation_id, timeout=120)
```

The poller backs off from 0.5 s to 5 s and raises `OperationTimeoutError`, with the last state seen, when time runs out. `succeeded` means the command finished, not that an effect was permitted.

## Errors

Every failed request raises a `RailError` with `status`, `code`, `request_id` and the full `problem`. The subclasses match the TypeScript SDK: `BadRequestError`, `AuthenticationError`, `PermissionDeniedError`, `NotFoundError`, `ConflictError` and its `UnresolvedExternalEffectError`, `PreconditionFailedError`, `PayloadTooLargeError`, `UnprocessableError`, `RateLimitedError`, `UnavailableError` and `ServerError`.

```python
from rail_sdk import ConflictError, UnresolvedExternalEffectError

try:
    rail.call("createExecution", body, idempotency_key=key, headers={"Rail-Capability": capability})
except UnresolvedExternalEffectError:
    ...  # the target may already have acted: reconcile before any retry
except ConflictError as error:
    print(error.code, error.request_id)
```

A success response that doesn't match the contract also raises `RailError`; don't use it as evidence. Errors can be pickled, so they cross process boundaries.

## Retries

The client retries only `GET` requests answered `429` or `503` with `Retry-After`: `RailClient(..., max_attempts=3, max_retry_delay=30)`. **Mutations are never retried automatically.** If one fails, find out whether it took effect, then retry it yourself with the same idempotency key.

## Capabilities and certificates

`createExecution` takes a `Rail-Capability` header bound to the agent's client certificate, and a certificate-bound token is valid only over that certificate's TLS connection. Pass an `httpx.Client` configured with the certificate (`mtls_client` in `rail_sdk.auth`), or let the [governed helper](/sdks/governed-python) do all of this for you. Don't attach a capability to a client shared across unrelated operations.
