The reviewed repository CLI supports offline bundle inspection/verification and operator demo tooling. The newer **local preview** adds project initialization, provisioning, shared profiles, governed shell commands, approvals, and journey export. Those additions are absent from the repository default branch reviewed on September 26, 2026. Identify your supplied build using [implementation and release status](/get-started/implementation-status).

## Get the CLI

Obtain a versioned binary for your operating system and architecture, or a matching source workspace and build instructions, from your Rail operator. A public binary release or universal installer is not established by these docs.

```bash
rail version
```

Offline bundle verification needs the binary, a supported bundle, and a confirmed trust anchor. It works without a profile. See [offline verification](/cli/evidence).

## Command availability

| Command | Purpose | Baseline |
| --- | --- | --- |
| `rail bundle inspect`, `rail verify` | Inspect and verify supported bundles offline | Repository and preview |
| `rail init`, `rail dev` | Initialize and provision a project | Local preview only |
| `rail login`, `rail whoami`, `rail logout` | Select and inspect a profile | Local preview only |
| `rail govern`, `rail govern resume` | Run an effect through authorization and dispatch gates | Local preview only |
| `rail grants`, `rail delegations`, `rail tokens` | Manage bounded authority | Local preview only |
| `rail executions`, `rail approvals` | Inspect state and vote as an enrolled approver | Local preview only |
| `rail receipts`, `rail policy` | Inspect evidence and policy pins | Local preview only |
| `rail journey export` | Export a grant journey's evidence | Local preview only |

Command availability and access depend on the supplied version and the profile's roles. A successful login does not grant authority to perform a protected action.
