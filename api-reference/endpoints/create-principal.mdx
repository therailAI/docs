<Note>Contract 0.1.1. **Try it** against your [local sandbox](/get-started/sandbox): run `rail sandbox up` and `rail sandbox trust`, then paste `rail sandbox token` as the bearer token. For any other environment, confirm that this operation is enabled there; `.invalid` hosts are placeholders.</Note>

**Required OAuth scope:** `platform:write`. Tenant, object, and domain authorization also apply.

Supply an explicit `Idempotency-Key`. See [idempotency and retries](/api-reference/idempotency).

This is a consequential operation. Credentials and OAuth scope alone do not authorize the effect; applicable authority and policy must also permit it.

**Service:** `platform`. Use its operator-provided base URL, or a gateway explicitly configured to route this operation. See [implementation and release status](/get-started/implementation-status).

## Implementation notes

Creates a principal record for the authenticated issuer. This does not update the service's active identity enrollment or issue a token. Your operator must provision the issuer/subject mapping, scopes, and project memberships separately.
