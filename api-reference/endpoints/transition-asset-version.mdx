**Required OAuth scope:** `registry:write`. Tenant, object, and domain authorization also apply.

Supply an explicit `Idempotency-Key`. See [idempotency and retries](/api-reference/idempotency).

**Service:** `registry`. Use its operator-provided base URL, or a gateway explicitly configured to route this operation. See [implementation and release status](/get-started/implementation-status).

## Implementation notes

The registry's policy gate requires an allow without unresolved obligations. A conditional approval requirement returns 503 registry_approval_profile_unavailable; other unhandled obligations return 503 registry_obligation_handler_unavailable. Approval support in execution does not imply the same support for registry transitions.
