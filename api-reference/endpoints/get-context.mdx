**Service:** `platform`. Use its operator-provided base URL, or a gateway explicitly configured to route this operation. See [implementation and release status](/get-started/implementation-status).

## Implementation notes

The reported project list includes enrolled memberships and projects owned by the caller. Ownership visibility here does not itself establish governance enrollment for another service.
