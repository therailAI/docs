**Required OAuth scope:** `edge:allocate`. Tenant, object, and domain authorization also apply.

Supply an explicit `Idempotency-Key`. See [idempotency and retries](/api-reference/idempotency).

This is a consequential operation. Credentials and OAuth scope alone do not authorize the effect; applicable authority and policy must also permit it.

**Service:** `edge`. Use its operator-provided base URL, or a gateway explicitly configured to route this operation. See [implementation and release status](/get-started/implementation-status).
