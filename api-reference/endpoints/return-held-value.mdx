<Note>Contract 0.1.1. The [local sandbox](/get-started/sandbox)'s default users don't hold `settlement:return`, so the playground gets `403` here. For any other environment, confirm that this operation is enabled there; `.invalid` hosts are placeholders.</Note>

**Required OAuth scope:** `settlement:return`. Tenant, object, and domain authorization also apply.

Supply an explicit `Idempotency-Key`. See [idempotency and retries](/api-reference/idempotency).

This is a consequential operation. Credentials and OAuth scope alone do not authorize the effect; applicable authority and policy must also permit it.

**Service:** `settlement`. Use its operator-provided base URL, or a gateway explicitly configured to route this operation. See [implementation and release status](/get-started/implementation-status).
