<Note>Contract 0.1.1. Confirm that this operation is enabled in your deployment. Example hosts are placeholders; this page does not send API requests.</Note>

**Required OAuth scope:** `events:write`. Tenant, object, and domain authorization also apply.

Supply an explicit `Idempotency-Key`. See [idempotency and retries](/api-reference/idempotency).

**Service:** `events`. Use its operator-provided base URL, or a gateway explicitly configured to route this operation. See [implementation and release status](/get-started/implementation-status).

## Implementation notes

The HTTPS destination's hostname must be approved by the deployment operator before subscription creation. An unapproved hostname returns 422 webhook_destination_not_allowed. Ownership verification and outbound public-address checks also apply; a syntactically valid URL alone is insufficient.
