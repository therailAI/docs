---
title: "Exchanges API — Convert Between Fiat and Digital Assets"
sidebarTitle: "Exchanges"
description: "Create and track asset exchanges between a customer's accounts. Convert fiat to crypto, crypto to fiat, or swap digital assets at live exchange rates."
---

An Exchange converts funds from one asset type to another between two of a customer's [Accounts](/api-reference/accounts) — for example, converting USD to ETH (an on-ramp), ETH back to USD (an off-ramp), or swapping between two digital assets. The source and destination accounts must belong to the same customer but hold different asset types. Rail applies a real-time exchange rate at the moment the exchange is executed; the `exchange_rate` and `destination_amount` in the response reflect the locked-in rate for that transaction.

---

## POST /v1/exchanges

Creates a new exchange request. Rail will calculate the `destination_amount` automatically based on the prevailing exchange rate. You specify the `source_amount` you want to convert.

<ParamField body="source_account_id" type="string" required>
  The ID of the account to debit (e.g. `CUST001.USD.001`). Must hold `source_asset_type`.
</ParamField>

<ParamField body="destination_account_id" type="string" required>
  The ID of the account to credit (e.g. `CUST001.ETH.001`). Must hold `destination_asset_type`.
</ParamField>

<ParamField body="source_amount" type="number" required>
  The amount of `source_asset_type` to convert. The equivalent `destination_amount` is calculated by Rail.
</ParamField>

<ParamField body="source_asset_type" type="string" required>
  The asset to sell or convert from (e.g. `FIAT_USD`, `FIAT_TESTNET_USD`).
</ParamField>

<ParamField body="destination_asset_type" type="string" required>
  The asset to buy or convert to (e.g. `ETHEREUM_MAINNET_ETH`, `BITCOIN_MAINNET_BTC`).
</ParamField>

<ParamField body="idempotency_key" type="string">
  A unique key to safely retry the request without creating duplicate exchanges. See [Idempotency](/api-reference/idempotency).
</ParamField>

<Warning>
  Exchange rates are locked at the time the exchange is created and are non-negotiable after creation. Rail does not support limit orders or rate guarantees on the API. If you need a rate quote before committing, contact your Rail representative about pre-trade quotes.
</Warning>

```bash
curl -X POST https://sandbox.layer2financial.com/api/v1/exchanges \
  -H "Authorization: Bearer {AUTH_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "source_account_id": "CUST001.USD.001",
    "destination_account_id": "CUST001.ETH.001",
    "source_amount": 1000.00,
    "source_asset_type": "FIAT_USD",
    "destination_asset_type": "ETHEREUM_MAINNET_ETH",
    "idempotency_key": "exchange-20240121-001"
  }'
```

<ResponseField name="data" type="object">
  The newly created exchange object.
  <Expandable title="data fields">
    <ResponseField name="id" type="string">
      Unique exchange identifier (e.g. `exg_abc001`).
    </ResponseField>
    <ResponseField name="source_account_id" type="string">
      The account that was debited.
    </ResponseField>
    <ResponseField name="destination_account_id" type="string">
      The account that was credited.
    </ResponseField>
    <ResponseField name="source_amount" type="number">
      The amount debited from the source account.
    </ResponseField>
    <ResponseField name="source_asset_type" type="string">
      The asset sold.
    </ResponseField>
    <ResponseField name="destination_amount" type="number">
      The amount credited to the destination account, calculated at the locked exchange rate.
    </ResponseField>
    <ResponseField name="destination_asset_type" type="string">
      The asset purchased.
    </ResponseField>
    <ResponseField name="exchange_rate" type="number">
      The rate applied: `destination_amount / source_amount`.
    </ResponseField>
    <ResponseField name="status" type="string">
      Current exchange status. See status lifecycle below.
    </ResponseField>
    <ResponseField name="fee" type="object">
      Fee charged for the exchange, if applicable.
      <Expandable title="fee fields">
        <ResponseField name="amount" type="number">Fee amount.</ResponseField>
        <ResponseField name="asset_type" type="string">Asset in which the fee was charged.</ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 creation timestamp.</ResponseField>
    <ResponseField name="updated_at" type="string">ISO 8601 last-update timestamp.</ResponseField>
    <ResponseField name="completed_at" type="string">ISO 8601 completion timestamp. `null` if still in progress.</ResponseField>
  </Expandable>
</ResponseField>

```json
{
  "data": {
    "id": "exg_abc001",
    "source_account_id": "CUST001.USD.001",
    "destination_account_id": "CUST001.ETH.001",
    "source_amount": 1000.00,
    "source_asset_type": "FIAT_USD",
    "destination_amount": 0.3215,
    "destination_asset_type": "ETHEREUM_MAINNET_ETH",
    "exchange_rate": 0.0003215,
    "status": "COMPLETED",
    "fee": {
      "amount": 2.50,
      "asset_type": "FIAT_USD"
    },
    "created_at": "2024-01-21T12:00:00Z",
    "updated_at": "2024-01-21T12:00:08Z",
    "completed_at": "2024-01-21T12:00:08Z"
  }
}
```

**Exchange status lifecycle:**

| Status | Description |
|--------|-------------|
| `REQUESTED` | Exchange request accepted and queued. |
| `PROCESSING` | Rate locked; debit and credit operations in progress. |
| `COMPLETED` | Both accounts updated; exchange finalized. |
| `FAILED` | Exchange could not be completed (e.g. insufficient balance or rate unavailable). |

## GET /v1/exchanges

Returns a paginated list of all exchanges for your platform.

<ParamField query="source_account_id" type="string">
  Filter by the source (debited) account.
</ParamField>

<ParamField query="destination_account_id" type="string">
  Filter by the destination (credited) account.
</ParamField>

<ParamField query="status" type="string">
  Filter by exchange status: `REQUESTED`, `PROCESSING`, `COMPLETED`, or `FAILED`.
</ParamField>

<ParamField query="source_asset_type" type="string">
  Filter by the asset sold (e.g. `FIAT_USD`).
</ParamField>

<ParamField query="destination_asset_type" type="string">
  Filter by the asset bought (e.g. `ETHEREUM_MAINNET_ETH`).
</ParamField>

<ParamField query="from_date" type="string">
  Return exchanges created on or after this ISO 8601 datetime.
</ParamField>

<ParamField query="to_date" type="string">
  Return exchanges created on or before this ISO 8601 datetime.
</ParamField>

<ParamField query="page" type="integer">Page number. Defaults to `1`.</ParamField>
<ParamField query="page_size" type="integer">Results per page. Defaults to `20`, maximum `100`.</ParamField>

```bash
curl -X GET "https://sandbox.layer2financial.com/api/v1/exchanges?source_account_id=CUST001.USD.001&status=COMPLETED" \
  -H "Authorization: Bearer {AUTH_TOKEN}"
```

<ResponseField name="data" type="array">
  Array of exchange objects.
</ResponseField>

<ResponseField name="pagination" type="object">

</ResponseField>

## GET /v1/exchanges/{exchange_id}

Retrieves full details for a single exchange by its ID.

<ParamField path="exchange_id" type="string" required>
  The unique exchange identifier (e.g. `exg_abc001`).
</ParamField>

```bash
curl -X GET https://sandbox.layer2financial.com/api/v1/exchanges/exg_abc001 \
  -H "Authorization: Bearer {AUTH_TOKEN}"
```

<ResponseField name="data" type="object">
  Full exchange object.
  <Expandable title="data fields">
    <ResponseField name="id" type="string">Exchange identifier.</ResponseField>
    <ResponseField name="source_account_id" type="string">Debited account.</ResponseField>
    <ResponseField name="destination_account_id" type="string">Credited account.</ResponseField>
    <ResponseField name="source_amount" type="number">Amount converted from.</ResponseField>
    <ResponseField name="source_asset_type" type="string">Asset sold.</ResponseField>
    <ResponseField name="destination_amount" type="number">Amount received.</ResponseField>
    <ResponseField name="destination_asset_type" type="string">Asset bought.</ResponseField>
    <ResponseField name="exchange_rate" type="number">Locked rate applied.</ResponseField>
    <ResponseField name="status" type="string">Current status.</ResponseField>
    <ResponseField name="fee" type="object">Fee details.</ResponseField>
    <ResponseField name="failure_reason" type="string">
      Reason for failure if status is `FAILED`. `null` otherwise.
    </ResponseField>
    <ResponseField name="created_at" type="string">Creation timestamp.</ResponseField>
    <ResponseField name="updated_at" type="string">Last-update timestamp.</ResponseField>
    <ResponseField name="completed_at" type="string">Completion timestamp, or `null`.</ResponseField>
  </Expandable>
</ResponseField>

```json

  "data": {
    "id": "exg_abc001",

    "updated_at": "2024-01-21T12:00:08Z",
```

<Tip>
  Exchanges power crypto on-ramp and off-ramp use cases. To see how to build a complete on-ramp flow (user deposits USD → converts to ETH → withdraws to wallet), see the [Crypto On-Ramp](/use-cases/crypto-onramp) guide. For the reverse, see [Crypto Off-Ramp](/use-cases/crypto-offramp).
</Tip>

<Note>
  For transfers between accounts of the same asset type, use the [Transfers API](/api-reference/transfers). For the full guide on exchanges, see [Transfers & Exchanges](/guides/transfers-exchanges).
</Note>
